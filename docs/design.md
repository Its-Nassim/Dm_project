# Hallmark · Studio design notes

This project uses a restrained Hallmark-inspired system: warm neutrals, a measured editorial voice, and a single, confident accent color. The interface keeps to a narrow width, strong spacing rhythm, and simple controls so the product stays readable and calm.

## Layout
- Use a centered shell with generous gutters and consistent rhythm.
- The hero sits in a strong column composition with the primary call to action first.
- Cards remain light and low-noise, with crisp borders and consistent radii.

## Typography
- Headlines are not italicized or decorated.
- Body text is readable and calm; labels are sentence case and untracked.
- Use the theme's scale and weights, with generous line height.

## Interactions
- All controls need clear focus states and visible hover/pressed states.
- Motion is subtle and limited to opacity and translate values.
- Respect reduced motion preferences.

## Imagery
- Use product-first photography or neutral placeholders rather than stock-heavy templates.
- Credits remain visible when a library photo is used.

## Accessibility
- Respect 4.5:1 text contrast and 3:1 control contrast.
- Keep tap targets generous and keyboard focus obvious.
- Content remains readable without annotations or color alone as the only signal.
